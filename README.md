# BioCycle - Bio-Waste to Value Assistant

BioCycle is a beginner-friendly student project that helps users understand how organic waste can be separated, treated, and reused.

## Problem

Organic waste is often mixed with other waste, making it harder to manage and recover useful materials. Beginners may also be unsure which treatment approach fits different types of bio-waste.

## Solution

BioCycle provides a simple educational interface for exploring common organic-waste categories and learning about possible next steps such as composting, vermicomposting, and biogas production.

## Features

- Offline chatbot with responses to common bio-waste questions
- Quick questions for vegetable waste, composting, vermicomposting, and biogas
- Four-step BioCycle process: Identify, Separate, Treat, and Reuse
- Sustainability impact overview
- Waste category cards for kitchen, garden, fruit and vegetable, and other organic waste
- Responsive layout for phones and laptops
- Runs locally without a backend or external API

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.

The project works by opening `index.html` directly. No installation, build step, server, or external service is required.
